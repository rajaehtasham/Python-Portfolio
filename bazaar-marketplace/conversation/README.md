# Bazaar Marketplace

[![Live Demo](https://img.shields.io/badge/Live_Demo-Railway-00C7B7?style=for-the-badge&logo=railway&logoColor=white)](https://python-portfolio-production.up.railway.app/)

**Live Application URL:** [https://python-portfolio-production.up.railway.app/](https://python-portfolio-production.up.railway.app/)

A full-stack e-commerce marketplace platform built with Django 6 and Tailwind CSS. The application allows users to list items for sale, browse products by categories, and communicate directly with sellers through an in-app messaging system.


## Features

- **User Authentication:** Registration, login, and logout functionality.
- **Item Management:** Create, edit, and delete product listings with image uploads.
- **Category Filtering & Search:** Search products by keyword and filter by category.
- **In-App Messaging System:** Real-time buyer-to-seller chat threads linked directly to product listings.
- **User Dashboard:** Dedicated dashboard for vendors to manage their active listings.
- **Responsive UI:** Custom-styled using Tailwind CSS.


## Tech Stack

- **Backend:** Python / Django 6
- **Frontend:** HTML5, Tailwind CSS
- **Database:** SQLite (Development) / PostgreSQL (Production)
- **Deployment:** Railway
- **Environment Management:** Python `venv`
